# Copy-and-Paste-Grid-data-to-Blazor-Scheduler

## Repository Description

This repository contains a practical example demonstrating how to copy data from a data grid and paste it directly into a Blazor Scheduler component within a .NET 8 Blazor Web App application. It showcases clipboard integration capabilities for efficient data transfer between UI components.

## Overview

This project is a BlazorSchedulerClipboard example showing how to implement copy and paste Grid data functionality in Blazor Scheduler within a .NET8 Blazor Web App application. The example provides a complete working solution with step-by-step instructions.

## Features

* Copy data from grid components
* Paste data seamlessly into Blazor Scheduler
* Support for .NET 8 Blazor Web App framework
* Complete clipboard integration example
* Easy-to-follow implementation guide

## Prerequisites

* Visual Studio 2022
* .NET 8 SDK
* Syncfusion Blazor NuGet packages

## Installation

1. Checkout this project to a location on your disk
2. Open the solution file in Visual Studio 2022
3. Restore the NuGet packages by rebuilding the solution
4. Build the project successfully

## How to run the project

1. Checkout this project to a location in your disk
2. Open the specified application from the `.NET8 Blazor Web App` folder
3. Restore the NuGet packages by rebuilding the solution
4. Run the project using F5 or the Run button in Visual Studio
